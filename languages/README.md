# Translations

The plugin's text domain is `profitguard-for-woocommerce` and it is loaded from
this directory.

WordPress.org generates and serves translations automatically for plugins in the
directory, so no `.pot` file needs to be committed — translate.wordpress.org
builds it from the source. To generate one locally for testing:

```
wp i18n make-pot . languages/profitguard-for-woocommerce.pot
```
